# ChatGPT Prompt Navigator

## Installation on Safari

To install the ChatGPT Prompt Navigator extension on Safari, follow these steps:

1. **Enable Developer Mode**:
   - Open Safari.
   - Go to `Safari` > `Preferences` > `Advanced`.
   - Check the box that says `Show Develop menu in menu bar`.

2. **Load the Extension**:
   - Open the `Develop` menu in the menu bar.
   - Select `Show Extension Builder`.
   - Click the `+` button and choose `Add Extension`.
   - Navigate to the directory where the extension files are located and select it.
   - Click `Run` to load the extension.

## Checking if the Extension Works on Safari

To verify that the extension is working correctly on Safari, follow these steps:

1. **Open ChatGPT**:
   - Navigate to `https://chatgpt.com` in Safari.

2. **Check for Sidebar**:
   - The ChatGPT Prompt Navigator sidebar should appear on the right side of the screen.
   - If the sidebar is not visible, click the extension icon in the Safari toolbar to open it.

3. **Test Functionality**:
   - Use the search bar in the sidebar to search for prompts.
   - Click on a prompt to navigate to it in the chat.
   - Use the copy and export buttons to copy or export prompts.

If you encounter any issues, ensure that the extension is enabled in Safari's Extensions preferences and that you have the latest version of Safari installed.

## Installation on Edge

To install the ChatGPT Prompt Navigator extension on Edge, follow these steps:

1. **Enable Developer Mode**:
   - Open Edge.
   - Go to `Settings` > `Extensions`.
   - Enable the `Developer mode` toggle.

2. **Load the Extension**:
   - Click the `Load unpacked` button.
   - Navigate to the directory where the extension files are located and select it.
   - The extension should now be loaded and visible in the Edge toolbar.
